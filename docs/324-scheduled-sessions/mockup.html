Scheduled sessions — UI sketch

For discussion, not final visuals. The user sets up a schedule by asking the agent in chat and confirms it on a card (reqs 8, 9). All schedules are listed and edited in Settings → Schedules (reqs 10, 11, 24). Runs have their own sidebar view next to "needs you" (reqs 20–22). Nothing is added to the message input panel (req 12).
