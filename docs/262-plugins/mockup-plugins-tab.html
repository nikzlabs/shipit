docs/262 — the Plugins tab (right rail)

The plugin instrument panel lives as its own right-rail tab, beside Preview / Files / Issues — not in the chat column, whose PR card describes the work in flight. The tab renders only when the project declares plugins; everyone else pays zero rail space. Urgency escapes the tab as a warn dot on the tab label, so a closed tab can hide information but never a problem. Services themselves stay in Preview's services drawer (req 16 parity) with their origin badges — this tab manages the environment: versions, refresh, credentials, hosts, errors.
