Option A, one line per agent

Each running sub-agent gets its own short line just above the input: kind icon, name, a grey detail, time, spinner. Finished ones fold into one Finished subagents line under them, which you can open. There is no "Agents" label: the coloured icon at the start of each line says what it is. The sub-agent cards in the chat are gone: these lines are the only place sub-agents show. Hover a line for the full detail; click it to open its prompt, work and report. Every "Finished subagents" line in this page opens and closes when you click it.

Three ways to draw the lines

Same moment in all three: the main agent is working, three sub-agents run, two have finished.

1 · Plain lines. No frame; lines line up with "Working…". Lightest, but the lines can blur into the activity line.

2 · Quiet box Chosen Lines sit in a faint frame, like the queued-messages box. Clearly one group; costs ~8 px of frame.

3 · Guide line A thin line hangs the sub-agents under "Working…", so you read them as the main agent's helpers. No frame.

The quiet-box style in every state

a · Mid-turn: two running, one already done (folded). Hover shows the full "run on" line that the old card showed.

b · Same moment with Finished subagents opened: finished ones, newest first, ✓ green or ✗ red. With no cards in the chat, the block keeps every sub-agent of the session — it is the only record. A long list scrolls.

c · Turn ended, nothing running: the whole area is one line. A failure is shown in red on it, so it is not hidden by the fold.

d · Main agent idle, a background sub-agent still runs. Its line stays above Finished subagents until it finishes.

e · Phone width. The grey detail is cut first, the name second; time and status always stay.

f · No sub-agents in this session yet: nothing is drawn, no empty space.

Clicking a line

A click opens a full-size dialog over the whole app, the same kind ShipIt already uses for a ShipIt sub-agent's report. It holds everything the old card had, with room to read it. Esc, ✕ or a click on the dark backdrop closes it. The tabs in both dialogs work.

g · A Claude sub-agent, still running: Work shows every step live, Prompt what it was asked, Report fills in when it finishes.

h · A finished ShipIt sub-agent, opened from the Finished subagents list: the report, who ran it, time and cost.
