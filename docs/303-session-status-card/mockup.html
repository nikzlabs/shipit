Session status card — freshness variants

docs/303 req 14: the card always says whether it is current. Two states, one language for every cause (a question turn that did not update it, an actions turn, an ignored nudge). Each variant is drawn in both states, on a light and a dark theme, using the real theme tokens (--color-success, --color-attention, --color-attention-text). The grey bar under each pair is the composer.
