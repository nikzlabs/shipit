# Run — OpenCode 1.18.15, planning#434 fix verification (2026-08-18)

Sixth run of the [recipe](../plan.md); fourth for OpenCode. Purpose: verify
the planning#434 fix — `normalizeOpencodeToolResult`
(`session/agents/opencode/opencode-tool-normalizer.ts`) unwraps OpenCode's
`<task id=…><task_result>…</task_result></task>` result wrapper at the
Layer A boundary, so the persisted content IS the subagent's report and the
client's `skipHtml` markdown has no HTML block to swallow.

## Procedure

Dogfood drill per the recipe: `shipit service start dev`, fresh headless
session (`POST /api/sessions/headless`, `agent: "opencode"`,
`serviceId: "deepseek"`, seeded todo-list repo) with a subagent-only
prompt ("Spawn a subagent to count the files in the repo root and report
the number it found"). Persisted history read from `GET /history`; DOM
verified with Playwright.

Per the [08:18 run](2026-08-18-0818-opencode-1.18.15.md)'s lesson —
"rendered" means read the DOM, not the history row — the pass criterion
was the report text inside the `SubagentCall` card's report panel in the
accessibility tree, confirmed by screenshot. The page was opened only
after the turn finished, so this observation is the **rehydration path**
(HTTP bootstrap from persisted history), the exact surface that failed.
