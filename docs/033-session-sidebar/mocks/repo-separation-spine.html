4e extended — carrying the accent edge down the whole repo group

In 4e the per-repo hue lives on the header band's left border, so it labels the header. Running it the full height of the group makes it label the group: every session, the New session row, the PINNED and RECENTLY RESOLVED sub-sections all sit inside one continuous vertical claim. It also collapses the two ideas the earlier gallery kept separate — the band from variant 4 and the spine from variant 5 — into a single treatment, which is a point in its favour: one mechanism, two jobs.

All seven options below keep 4e's bg-tertiary band and differ only in how far the edge travels. Claude Light and Claude Dark, identical DOM, live sticky scrolling. Toggle Dense — eight hues stacked in a 272px rail is the failure mode to check for, not the four-repo case.

One implementation note that decides 5b vs the rest. The edge is drawn as border-left on the group, not on the header — so it paints behind the sticky band and the line stays continuous while the header is pinned. Put it on .ghead instead and the line visibly breaks at the seam the moment you scroll. Options 5c, 5e and 5g use an absolutely-positioned pseudo-element for the same reason (they need rounding or a gradient, which a border can't do), with z-index above the sticky header.
