Scheduled sessions — UI sketch (option A: the composer has a schedule mode)

A sketch for discussion, not a final design. The new-session composer is the editor for a schedule: the same target picker, the same toolbar (role, harness, model, reasoning, permission mode), and the same prompt box. A clock control adds a schedule row and turns Send into Create schedule. Because it is one component, a parameter that ShipIt adds to session start appears in schedules with no extra work (req 5).

Role is optional. With no role, the harness, model and reasoning pickers stand in its place, exactly as at normal session start. The prompt is the job; a role adds standing instructions only if the user picks one (req 6).
