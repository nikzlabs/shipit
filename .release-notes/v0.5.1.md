# ShipIt v0.5.1

54 commits since v0.5.0. This release makes package installs safe to share between sessions, locks down what a session can do to shared branches and to Docker, polishes the status card, and adds the newest models.

## New models and agent CLIs

The agent CLIs are updated, and GPT-6 Sol, GPT-6 Luna and Opus 5.5 are available to choose.

## Safer dependency sharing

- Each session and each plugin install has its own npm resolution cache and its own pnpm store, so one session can no longer corrupt another's installs.
- A new verified pnpm base lets eligible repos share a prebuilt `node_modules`. Eligibility now covers workspace links, patched dependencies, a committed `.pnpmfile.mjs`, and repos whose dependencies build at install time (through a pruned base). The base stays switched off until `pnpm add` works over it (planning#606).

## Branch and Docker safety

- A session can no longer push normally to a shared branch, fork onto one, publish a base branch, or force-push only to rewind history.
- The Docker proxy mounts the exact path it checked, rejects ambiguous field casing, and cleans the exec request body.
- ShipIt repairs a frozen local default branch when it gives a checkout back to a session.
- A project's own git hooks now run on ShipIt's auto-commit.

## Status card

- Every field of the card is rendered as markdown.
- The card can collapse to a single icon, and it sits directly above the composer on a short or still-loading conversation.
- A sent row keeps the tick it had when it was sent. A retried attempt reads the card as it is now.

## Sessions and cross-session work

- To send a message to a session that the agent cannot reach, the agent now proposes it as a card, and your click delivers it.
- `shipit-preview://` links work as an iframe `src`, so a presented page can embed a Compose service by name.
- The per-parent child limit counts only children that are not finished. Agents can no longer archive sessions; only you can.
- The conversation replay goes to the agent that actually runs, and it includes the work, not only the words.

## Reliability

- An agent CLI, a git-LFS timeout, and a browser that is still rendering at the end of a turn are all stopped as a whole process tree. The orchestrator container runs with an init shim, so orphaned processes are cleaned up.
- When you open a session, it stays at the end until the conversation has painted. A brief switch away keeps the connection instead of replacing it.
- Present links work across all workspace path forms, and OpenAI subscription limits update correctly for OpenCode.
