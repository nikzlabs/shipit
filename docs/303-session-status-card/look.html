Session status card — the look

Brief: “the card is very bleak, blends with the conversation text.” Four skins for the same card, in the card's real place: a transcript tail above, the composer below. Nothing about what the card says changes — same sections, same rows, same “Stale” label in the accent colour at the bottom right (req 14), same full rows with descriptions and badges (reqs 17, 19, 29). Only the surface changes. Semantic tokens only, so every skin holds in all 20 themes.

  • 0 · Today — 50 % surface, 60 % border. The baseline you are reacting to.
  • A · Solid — the same card at full opacity: exactly the surface the transcript's follow-up action card already uses.
  • B · Spine — solid, plus a 3 px accent rail down the left edge, so the card has an identity of its own at a glance. ← recommended
  • C · Panel — an elevated surface with a shadow, and the section icons in accent-tinted chips: the card reads as a panel laid over the conversation.
  • D · Tray — solid card, with the tickable sections and the buttons recessed onto a tertiary tray, so the controls separate from the prose.

Note on C and D: an unticked checkbox is drawn in --color-border-primary, which on the raised (C) and recessed (D) surfaces is very close to the surface itself — look at the dark boards, where the empty boxes all but vanish. Either would need the checkbox border raised to --color-border-secondary as part of the change, which touches the shared checklist the transcript action card uses too.
