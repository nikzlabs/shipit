Why Briefcase. docs/264 defines a role as “what an agent runs on and, optionally, what job it is for” — a briefcase is that second half, and the app uses the glyph nowhere else, so it carries no competing meaning here. It also wins on legibility, which only showed up once these were rendered at real size: IdentificationBadge and UserGear both put fine internal detail (a portrait, a gear) inside a 16px box, and at the 13px composer chip they smudge. Anything person-shaped also competes with Robot, which sits one row below as the harness.
