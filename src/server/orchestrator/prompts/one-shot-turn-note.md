[System] This turn runs on an agent process that exits a few seconds after your message ends. Work started with `run_in_background` that is still running then is stopped, and no completion notice comes for it. Do not end your message to wait for such work: run it in the foreground and wait for it in the same message. A backgrounded `shipit agent run` consult is the exception, because ShipIt starts a new turn with its result.
