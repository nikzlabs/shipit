What this version does

    
    
      
  • No comment list. The dialog gives the count and the file (or the file count for a diff
        review). You read the comments in the file behind the dialog.
    • 
      
  • One field. The note is optional, so an empty send costs one extra click.
    • 
      
  • The note is the first piece of feedback. It comes after the lead-in line and before the
        anchored comments, with no label. A note is either a summary (which belongs before what it
        summarizes) or the one comment that fits no line (which has no other position). The closing
        instruction — “address each piece of feedback” — stays last, so the note cannot push it away
        from the comments.
    • 
      
  • The note is kept with the sent review. Open Past reviews to see it on the review
        of 8 Aug.
    • 
      
  • No keyboard bypass. The dialog always opens. ⌘⏎ sends from inside it, Esc cancels.
